### Stock Take & Reconciliation Suite
**Power Platform &nbsp;·&nbsp; 2026**

Replaces paper count sheets and month-end Excel reconciliation for a coffee exporter's warehouses.

`Power Apps` `Dataverse` `Power Automate` `React` `TypeScript`

<details>
<summary><b>What's inside</b></summary>
<br>

- **Counter phone app:** outturn-first, blind counting (counters never see system quantities), tag photos, offline queueing, floor map
- **Management hub:** ERP import checks, approvals, a variance engine that suggests the cause of every difference, SLA escalation, a four-gate sign-off, 12 Excel reports
- **Dataverse:** 20 tables, 7 security roles, ERP data locked against edits, full audit
- **12 flows:** Teams alerts, Finance approvals, escalation, an emailed month-end pack, and a report the morning after every count
- **Infrastructure as code:** schema, roles, seed data and flows rebuilt from scripts

</details>

### Kenya Trade Intelligence Platform
**Next.js &nbsp;·&nbsp; Postgres &nbsp;·&nbsp; AI &nbsp;·&nbsp; 2025–26**

One decision-support platform for Kenya's State Department for Trade.

`Next.js 16` `Postgres` `Drizzle` `Claude API` `NextAuth`

<details>
<summary><b>What's inside</b></summary>
<br>

- **Eight tools:** explorer, landed-cost estimator, opportunity engine (seven-factor SQL score), barrier monitor, exporter map, procedures, live news, dashboards
- **AI Trade Analyst:** Claude with a single read-only SQL tool, so every answer comes from a real query
- **Data at scale:** 2.7M+ rows on Neon Postgres, Superset BI views, World Bank tariff sync, NewsAPI ingestion
- **Accounts:** self-hosted auth (email plus four OAuth providers), watchlists, notifications
- **Automation:** scheduled jobs on GitHub Actions

</details>
