## Featured Work

### Stock Take & Reconciliation Suite
> Power Platform solution replacing paper count sheets and month-end Excel reconciliation for a coffee exporter's warehouses

- **Counter phone app** — outturn-first, *blind* counting (counters never see system quantities, so counts stay honest), one-pocket-per-lot rule, tag photos, offline queueing, stack checklist and floor map
- **Management hub** — ERP stock import with validation checks, count-sheet approvals, a variance engine that suggests the likely cause of every difference, exceptions with SLA escalation, mapping approvals, a 4-gate sign-off, and 12 live reports exported to Excel
- **Dataverse back end** — 20 tables, 7 security roles, ERP data locked against edits, full auditing, photos as attachments
- **12 Power Automate flows** — Teams alerts to supervisors and counters, Finance approvals, daily exception escalation, a sign-off chain that emails the month-end pack, and a count report the morning after every count
- **Infrastructure as code** — schema, roles, seed data and flows all rebuilt from Node scripts over the Dataverse Web API
- **Stack:** Power Apps (code apps) · React · TypeScript · Vite · Dataverse · Power Automate · Teams · Approvals

---

### Kenya Trade Intelligence Platform (KTIP)
> Trade decision-support platform for Kenya's State Department for Trade

- **One view of fragmented trade data** — transactions, tariffs, trade agreements, non-tariff barriers, exporter capacity and procedures, each traceable to its source agency
- **8 tools** — product & market explorer, landed-cost estimator, market opportunity engine (7-dimension score computed in SQL), barrier monitor, exporter capacity map, step-by-step procedures, live trade news, embedded BI dashboards
- **AI Trade Analyst** — Claude with a single hardened, read-only SQL tool: every answer comes from a query it actually ran (streaming, prompt caching, rate limiting)
- **Data at scale** — 2.7M+ transaction rows on Neon Postgres, BI views for Apache Superset, real World Bank WITS tariff sync and NewsAPI ingestion on GitHub Actions
- **Accounts** — self-hosted NextAuth (email/password + Google, LinkedIn, GitHub, Facebook), watchlists, in-app and email notifications
- **Stack:** Next.js 16 · React 19 · TypeScript · PostgreSQL (Neon) · Drizzle ORM · Tailwind · Claude API · NextAuth · GitHub Actions

### NSIF South Sudan Platform
> Government-grade social insurance platform for the Republic of South Sudan

- **Public website** with Sanity CMS, i18n (English/Arabic), and full accessibility
